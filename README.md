template
Fișa proiectului / Project Record

1. Titlul proiectului / Project Title
Denumirea standardizată pe care o folosești în arhivă.

2. Autor / Architect
Arhitectul/autorii principali.

3. Colaboratori / Collaborators
Cu rolul precizat când îl cunoști: arhitect, inginer structurist, designer, artist etc. Aș păstra neapărat și rolul, nu doar numele.

4. Beneficiar / Client

5. Anul proiectării / Design Year
Poate fi și interval: 1944–1946.

6. Categorie / Category

7. Tipologie / Building Type

8. Adresă inițială / Original Address

9. Adresă actuală / Current Address

10. Statutul proiectului / Project Status
Aici aș crea un vocabular fix, de exemplu:
Built / Unbuilt / Competition Entry / Unknown.

11. Starea actuală / Current Condition
Altceva decât statutul proiectului. De exemplu:
Existing / Altered / Significantly Altered / Demolished / Unknown.

12. Documentație de arhivă / Archival Documentation
De exemplu:
APMB, Dosar 316/1933, I Galben
sau fondul UAUIM, arhiva familiei etc.

13. Credite imagini / Image Credits
